# opt_engine

`opt_engine` contains the type-safe Rust optimization primitives used by
[HOLA](https://github.com/blackrock/HOLA): parameter spaces, scales, search
strategies, leaderboards, and checkpoint persistence.

This crate is an internal HOLA implementation layer and does not currently
carry the same API stability guarantee as the Python, CLI, and REST interfaces.
See its [API documentation](https://docs.rs/opt_engine) or the
[HOLA documentation](https://github.com/blackrock/HOLA/blob/main/docs/index.md)
for details.
