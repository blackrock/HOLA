# hola

`hola` is the dynamic orchestration layer for
[HOLA](https://github.com/blackrock/HOLA). It turns runtime study
configuration into an asynchronous optimization engine and, with the optional
`server` feature, exposes that engine through HOLA's REST API.

See the [crate API documentation](https://docs.rs/hola) and the
[HOLA user documentation](https://github.com/blackrock/HOLA/blob/main/docs/index.md)
for configuration, distributed operation, persistence, and security guidance.
